# Michelle Geldenhuys, MCIPS · AI in Action

Professional portfolio website: a procurement and operations professional who finds the bottleneck in a business process and builds a practical AI-assisted tool to remove it.

**Live site:** https://micha-code15.github.io/Professional-portfolio-AI-in-Action/

## What's here
| Page | What it is |
|---|---|
| `index.html` | Home page: selected work, live demos, videos, approach |
| `project-breakdowns.html` | Full case studies, including stamp-and-sign, configurator and event-platform demos |
| `product-search.html` | Working demo: plain-language product search with weighted match scoring |
| `crm-demo.html` | Working demo: key account workspace (today view, accounts, pipeline, quotes) |
| `3d-demo.html` | Working demo: interactive 3D product viewer with parts list and document cross-check |

Plain HTML, CSS and JavaScript with no build step. Three.js, pdf-lib and JSZip load from public CDNs.

## Privacy
All public demonstrations use the fictional company "Example Manufacturing Group" and synthetic data. No real employer, client, supplier, price or document appears on this site, and no performance figure on it is presented as an audited result.
